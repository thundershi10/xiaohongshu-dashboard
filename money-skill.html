money.skill

个人技能 → 数字产品 → 被动收入系统｜10 prompt × 5 阶段的可执行框架

框架版本：v1.0 适用人群：有一项技能、想做被动收入的个人 交付方式：复制 prompt → 填槽 → 执行
prompt 总数10
阶段数5
产品阶梯层数4
最短上线周期7 天

这套框架解决的 3 个问题

  1. 不知道做什么：用 Prompt 1 / 5 / 7 从已有技能挖出 15+ 个产品点子。
  2. 不知道能不能卖：用 Prompt 4 / 6 提前做需求验证与最快上线测试。
  3. 不知道怎么卖：用 Prompt 3 / 8 / 9 / 10 完成阶梯、大纲、定价、平台选择。

本质

这不是 10 个零散的 prompt，而是一条从「我会什么」到「我能卖什么」再到「我在哪卖」的最短路径。每一阶段的产出，是下一阶段的输入。

顺序建议

新手建议路径：P6 → P4 → P1 → P7 → P5 → P3 → P2 → P8 → P9 → P10。
先验证再设计，先小后大，先快速上线再做阶梯。

谁不适合用

没有任何技能积累的人不适合。这个框架默认你已经在某件事上比 80% 的人更熟练，否则前几个 prompt 的输出会非常空。

阶段 1 · 快速验证

先看能不能卖

在花一周时间做产品之前，先用这两个 prompt 验证「需求是否存在」和「最快能产出什么」。

P4 · 7 天内可以上线的最快产品

需要填的槽

[skill] 你的技能　[X] 每天可投入小时数　[audience] 目标用户

产出

7 个可在 7 天内完成的产品方案，含：每日计划 / 所需工具 / 预计售价 / 难度 / 最佳推荐。

什么时候用

你想立刻动手、不想再陷在「想点子」里。

我想用 [skill] 在 7 天内做一个被动收入产品。我每天能投入 [X] 小时，目标用户是 [audience]。给我 7 个可以快速完成的产品方案。每个方案包含：每日制作计划、所需工具、预计售价、难度评估，并标出最适合快速出单的最佳方案。

P6 · 验证哪些产品真的能卖钱

需要填的槽

[skill]　[audience]

产出

10 个产品点子 × 5 维度打分（需求 / 紧迫性 / 制作难度 / 差异化 / 购买可能性），并指出最快变现的 3 个。

什么时候用

你已经有一堆点子，但不知道哪个最值得做。

扮演市场验证研究员。我想基于 [skill] 向 [audience] 售卖被动收入产品。给我 10 个产品点子，并从需求、紧迫性、制作难度、差异化、购买可能性这 5 个维度打分（1-10 分）。最后指出最有可能最快变现的 3 个产品，并解释原因。

阶段 2 · 找产品机会

三种挖法

从三个不同的口子去找产品点子：技能本身 (P1) / 用户真实问题 (P5) / 已有经验 (P7)。三个一起用，重叠的点子最值得做。

P1 · 从技能挖掘可盈利的被动收入点

需要填的槽

[skill]　[beginner/intermediate/expert]　[audience]

产出

15 个产品点子，含：产品 / 谁买 / 解决什么 / 难度 / 速度 / 平台，按「最容易赚钱 → 长期潜力最高」排序。

你是商业咨询策略师。我的技能是 [skill]，我的经验水平是 [beginner/intermediate/expert]，目标受众是 [audience]。给我 15 个可以基于这个技能打造的被动收入产品点子。每个点子需要包含：产品是什么、谁会买、解决什么问题、制作难度、上线速度、最适合的销售平台。并按"最容易赚钱 → 长期潜力最高"排序。

P5 · 把技能匹配到真实需求

需要填的槽

[skill]　[audience]

产出

15 个用户「正在主动解决」的问题，每个问题转化成一个产品点子，含承诺改变和购买动机。

我具备 [skill]，目标用户是 [audience]。列出这个人群正在主动解决的 15 个真实问题，并基于这些问题转化为被动收入产品点子。每个点子需包含：问题、产品方案、承诺的改变结果，以及用户购买动机。

P7 · 从已有经验中挖掘产品

需要填的槽

[skill]

产出

从「常做的事 / 常解释的问题 / 常用捷径 / 常见错误 / 已有方法论」中提取 10 个产品，含形式 / 标题思路 / 目标用户。

我不想从 0 开始。帮我把已有的 [skill] 经验转化为产品。分析我经常做的事情、经常解释的问题、常用捷径、常见错误，以及已有的方法论。然后转化为 10 个被动收入产品，并附上产品形式、标题思路和目标用户。

阶段 3 · 做产品设计

从形态到大纲

把验证过的方向落到「具体长什么样」：先用 P2 做新手版形态，再用 P3 拉成产品阶梯，最后用 P8 写出可执行的内容大纲。

P2 · 把一个技能转化为适合新手的数字产品

需要填的槽

[skill]　[audience]

产出

10 个无技术门槛方案，优先使用 Google Docs / Canva / Notion / 表格，含名称 / 形式 / 价格区间 / 制作步骤 / 为什么有人买。

帮我把 [skill] 转化为简单易做的数字产品，目标用户是 [audience]。给我 10 个不需要复杂技术的产品方案，优先使用 Google Docs、Canva、Notion 或表格等工具完成。每个方案包含：产品名称、形式、价格区间、制作步骤，以及为什么有人会买。

P3 · 设计从低价到高价的产品阶梯

需要填的槽

[skill]　[audience]

产出

4 层阶梯（低 / 中 / 高 / 订阅），每层包含：卖什么 / 价格区间 / 交付形式 / 用户类型 / 怎么承接下一层。

扮演产品体系专家。我的技能是 [skill]，受众是 [audience]。帮我设计一个 4 层产品阶梯：低价、中价、高价数字产品和持续订阅。每一层都要自然承接下一层。每层需说明：卖什么、价格区间、交付形式、用户类型，以及如何引导到下一个产品。

P8 · 生成完整产品大纲

需要填的槽

[audience]　[topic]　[product type]

产出

完整大纲：产品标题 / 核心承诺 / 模块结构 / 每部分内容 / 赠品 / 快速见效设计 / 交付形式。

我想为 [audience] 做一个关于 [topic] 的 [product type]。帮我生成完整大纲，包括：产品标题、核心承诺、模块结构、每一部分内容、附加赠品、快速见效设计，以及最终交付形式。要求简单实用、值得付费、避免学术化。

阶段 4 · 定价

三档对比 + 首发推荐

定价不靠拍脑袋，而是拿一份三档对照表去选。前期出单优先选「转化逻辑最顺」的那一档，而不是利润最高的那一档。

P9 · 给产品定一个合理价格

需要填的槽

[product idea]　[audience]

产出

低 / 中 / 高三档定价策略对比，含：包含什么 / 吸引谁 / 转化逻辑 / 优缺点 + 一个首发推荐价。

我有一个产品点子：[product idea]，目标用户是 [audience]。对比低价、中价、高价三种定价策略。分别说明每个价格应该包含什么、吸引哪类用户、转化逻辑，以及优缺点。最后给出一个适合前期快速出单的推荐价格。

阶段 5 · 分发销售

选一个，不要全做

新手最常见的错是同时上 5 个平台，结果哪个都做不起来。这个 prompt 帮你只选一个。

P10 · 选择最适合的销售平台

需要填的槽

[skill]　[product type]　[audience]　[goal]

产出

Gumroad / Etsy / Payhip / Shopify / Notion 市场 / 自建站 的对比 + 一条明确推荐。

我想卖一个与 [skill] 相关的被动收入产品。请对比 Gumroad、Etsy、Payhip、Shopify、Notion 市场或自建网站等平台。结合我的产品类型 [product type]、用户 [audience] 和目标 [goal]，推荐最适合的平台，并说明原因，包括手续费、搭建难度、流量潜力和新手友好度。

怎么用这套 prompt

第一次用

先跑 P6 + P4。在还没投入时间前，先确认有没有真实需求 + 能不能 7 天上线。

已经有一堆点子

跑 P6 做 5 维打分，挑出前 3 个再进 P8 写大纲，不要平铺。

已经有积累

从 P7 开始。比从 P1 起步更省力，因为你不是在「造」产品，而是在「翻译」经验。

填槽的写法

  • [skill] 越具体越好：写「给独立开发者写文案」比写「写作」好十倍。
  • [audience] 要带状态：写「刚开始做 Notion 模板的新手卖家」比写「Notion 用户」好。
  • [goal] 量化：写「30 天内出第一笔订单」比写「赚点钱」好。

常见错误

  • 跳过验证直接做产品 → 90% 的时间会浪费在卖不动的方向上。
  • 同时铺 5 个平台 → 哪个都跑不起来。
  • 第一款产品就做阶梯里的「高价」 → 应该先把低价跑通再上探。
